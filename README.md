# 🎮 tank.fahh

> **Fast-paced tank battles. Different maps. Smarter enemies. Survive the arena.**

**tank.fahh** is a futuristic browser-based tank battle game where you fight enemy tanks, collect power-ups, survive dangerous arenas, and push your skills from **AI Noob all the way to Godlike**.

Built to be fast, chaotic, competitive, and playable directly in your browser. 💥

---

## 🚀 Features

- 🎯 Fast-paced tank combat
- 🤖 6 AI difficulty levels
- 🗺️ 5 unique battle maps
- ⚡ Power-ups and special abilities
- 💀 Kills, score, XP and coins
- 🏆 Player progression
- 🌪️ Dynamic map hazards
- 📱 Responsive desktop and mobile gameplay
- 🎨 Cyberpunk / futuristic visual style
- 💾 Local progress saving
- ⚙️ Lightweight browser performance

# 🤖 AI Difficulty

Choose your opponent difficulty and see how far you can survive.

| Difficulty | Description |
|---|---|
| 🟢 **Noob** | Slow reactions, poor aim and predictable movement |
| 🔵 **Rookie** | Basic tracking, movement and combat |
| 🟣 **Pro** | Better aim, prediction and cover usage |
| 🟠 **Elite** | Flanking, smarter positioning and power-up usage |
| 🔴 **Nightmare** | Fast reactions, accurate attacks and aggressive tactics |
| 🟡 **Godlike** | Extreme prediction, advanced positioning and highly skilled behavior |

### 🟢 AI Noob

Easy opponent designed for beginners.

- Slow reactions
- Poor aim
- Predictable movement
- Rarely uses cover
- Slow target switching

### 🔵 AI Rookie

A basic but competent opponent.

- Better tracking
- Basic dodging
- Simple cover usage
- Basic power-up awareness

### 🟣 AI Pro

The real challenge begins.

- Predicts basic movement
- Uses cover
- Dodges projectiles
- Searches for power-ups
- Attempts basic flanking

### 🟠 AI Elite

A serious opponent.

- Accurate aim
- Fast reactions
- Advanced positioning
- Flanking
- Ambushes
- Strategic power-up usage

### 🔴 AI Nightmare

For players who want pain. 💀

- Very fast reactions
- Advanced dodging
- Projectile prediction
- Aggressive positioning
- Smart retreating
- Strong hazard awareness

### 🟡 AI Godlike

The ultimate challenge.

Godlike AI should feel **highly skilled, not like a cheater**.

It can:

- Predict movement
- Lead shots
- Flank
- Ambush
- Use cover
- Prioritize dangerous targets
- Adapt its strategy
- Use map hazards intelligently

It does **not** get infinite health, impossible speed, teleportation, or unfair information.

# ⚡ Gameplay

The objective is simple:

> **Destroy the enemy tanks and survive.**

During a match:

1. Choose your map.
2. Select an AI difficulty.
3. Enter the arena.
4. Fight enemy tanks.
5. Collect power-ups.
6. Avoid dangerous map zones.
7. Earn kills and score.
8. Survive until the battle is over.

# ⚡ Power-Ups

Power-ups can change the outcome of a fight.

Possible power-ups include:

- ❤️ **Health** — Restore HP
- 🛡️ **Shield** — Reduce incoming damage
- ⚡ **Speed** — Increase movement speed
- 🔥 **Damage Boost** — Increase damage
- 💨 **Rapid Fire** — Increase attack speed
- 💥 **Energy Burst** — Powerful area attack

Use them strategically instead of grabbing everything immediately.

# 📦 Running Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/tank.fahh.git
```

Enter the project:

```bash
cd tank.fahh
```

Then open the main HTML file in a modern browser.

For local development, you can also use a simple local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
